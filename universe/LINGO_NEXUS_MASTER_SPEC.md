# Lingo Nexus — New Universe Integration

## Canon rule

The Lingo Nexus is an original shared universe. Existing Lingo game models are treated as **mechanical and experiential source DNA**, not as immutable worlds.

We preserve useful gameplay patterns while re-authoring:
- world geography
- factions and institutions
- character identities
- narrative stakes
- visual language
- progression
- realm connections
- audio identity
- social systems
- live-event hooks

No title is considered production-complete merely because its architecture or catalog entry exists.

## Shared world

**Nexus Central** is the persistent hub connecting every realm through realm-gates.

Core shared systems:
1. Nexus ID
2. Legacy XP
3. virtual reward/economy contracts
4. inventory and entitlements
5. collections
6. achievements
7. quests and codex
8. party/presence
9. matchmaking
10. cloud-save contract
11. accessibility
12. notifications/news
13. seasonal live events
14. adaptive audio
15. shared asset registry

## Realm model

Every game is a realm of the same universe rather than an isolated application.

`Nexus Central → Realm Gate → Realm → Story/Modes → Return to Nexus`

Cross-realm continuity can unlock cosmetics, lore, achievements, collectibles, events and profile progression without requiring every game to share identical gameplay.

## Shared feature standard

Each realm should expose compatible interfaces for:
- story/campaign
- solo play
- multiplayer/co-op where appropriate
- mini-games
- stores/catalogs
- inventory/loadouts
- achievements
- progression
- audio director
- visual asset registry
- social/party systems
- accessibility
- save/load
- live-event hooks

## Production boundary

This catalog establishes development canon and integration contracts. It does **not** establish production deployment, Firebase credentials, Cloudflare activation, CI success, or live acceptance. Those remain governed by the existing evidence gates.
