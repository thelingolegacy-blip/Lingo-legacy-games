# Lingo Legacy Games Studio

Standalone original game portfolio for The Lingo Legacy.

## Titles
- Tricia's Escape — fantasy action-adventure
- Doughboy Oasis — persistent multiplayer virtual-world adventure
- Crazy Weasol's — dark-comedy 3D platform adventure
- Silly in Philly: The Streets — fictionalized urban open-world action comedy
- Jersey Shore & the Undead — cooperative survival horror

## Stack
- Next.js + React + TypeScript — studio web surfaces
- Flutter — cross-platform companion/mobile surfaces
- Firebase — identity, data and contract services only; no invented project credentials
- Cloudflare Workers/Pages — edge runtime and production delivery
- GitHub Actions — CI/CD and evidence
- Shared LINGO game-service contracts with isolated game state/economies

## Governance
This branch is a development foundation only. It does not authorize production deployment, domain promotion, Firebase mutation, or release activation.
